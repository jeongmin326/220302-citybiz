## 1. 비즈니스 환경 분석

### 1.1 소상공인·창업 지원 시장 현황

| 구분 | 내용 |
| :--- | :--- |
| **정책 배경** | 정부는 소상공인·중소기업 지원을 위해 매년 수십조 규모 정책자금 운용 |
| **디지털 전환** | 비대면 서비스 수요 급증 (코로나 이후 화상 상담, 원격 컨설팅 일반화) |
| **정보 비대칭** | 지원 제도 인지율이 낮아 실제 활용률이 지원 규모 대비 낮음 |
| **전문가 수요** | 창업 초기 법률·세무·노무 리스크 관리 수요 지속 증가 |

### 1.2 규제 및 법적 환경

| 항목 | 내용 |
| :--- | :--- |
| **개인정보보호법** | 회원 정보, 전문가 프로필, 상담 내용 처리 시 준수 필요 |
| **전자금융거래법** | 포인트 충전, 플랜 결제 관련 PG 연동 시 준수 |
| **변호사법·세무사법** | 법률·세무 정보 제공 서비스의 법적 범위 확인 필요 |
| **정보통신망법** | 회원 대상 서비스 운영 시 보안 의무 사항 |

## 2. 유사 시스템 사례 분석

| 서비스명 | 유형 | 유사 기능 | PublicService 차별점 |
| :--- | :--- | :--- | :--- |
| **창업넷 (k-startup.go.kr)** | 정부 포털 | 정책자금 정보 제공 | 전문가 매칭·화상 상담 추가 |
| **로톡 (lawtalk.co.kr)** | 법률 매칭 | 변호사 매칭, 채팅 상담 | 세무·노무·회계 등 다직종 통합 |
| **자비스 (jobis.co)** | 세무 자동화 | 세무 서비스 | 공간·정책자금 연계 없음 |
| **스페이스클라우드** | 공간 예약 | 공유공간 예약 | 전문가 연계 없음 |
| **CityBiz (자체 개발)** | 통합 포털 | 창업 지원 통합 검색 | AI 추천 특화, 유사 컨셉 |

**결론:** PublicService는 정책자금 + 전문가 매칭 + 공간 예약 + 화상 상담을 단일 플랫폼으로 통합하는 점에서 차별성 보유

## 3. 기술 환경 분석

### 3.1 선택 기술 환경

| 기술 | 선택 이유 | 비고 |
| :--- | :--- | :--- |
| **Spring Boot 3.5** | 국내 기업 표준 프레임워크, 생태계 풍부 | Jakarta EE 10 기반 |
| **Spring Data JPA** | 반복 DAO 코드 최소화, 쿼리 자동 생성 | Hibernate 6.x 사용 |
| **Spring Security** | 인증·인가 표준 솔루션 | 세션 기반 구성 |
| **MySQL** | 국내 중소 규모 웹 서비스 표준 DB | 오픈소스, 비용 효율 |
| **JSP + JSTL** | 기존 팀 숙련도 기반 | SPA 미채택 이유 |
| **WebSocket + WebRTC** | 실시간 양방향 통신 (화상통화) | 표준 웹 기술 |
| **Maven** | 의존성 관리, CI/CD 통합 용이 | Wrapper 포함 |

### 3.2 관련 외부 API 및 서비스

| 외부 서비스 | 용도 | 연동 방식 |
| :--- | :--- | :--- |
| **지오코딩 API** (Kakao/Naver 추정) | 전문가 위치 좌표 변환 | `GeocodingProxyController` 프록시 |
| **PortOne (구 아임포트)** | 결제 PG 연동 | `application.properties` 키 설정 필요 |
| **WebRTC STUN/TURN 서버** | 화상통화 P2P 연결 | `webrtc-client.js` 내 설정 |

## 4. 외부 데이터 분석

### 4.1 정책자금 데이터 구조

`PolicyFund` 엔티티를 통해 다음 유형의 데이터를 관리:

- 정부 기관별 정책자금 정보 (기관명, 지원 내용, 대상, 신청 기간 등)
- 사용자 스크랩(`PolicyScrap`) 연계로 개인화 북마크 제공

### 4.2 전문가 데이터 구조

5개 전문가 엔티티로 분리 관리:

| 엔티티 | 직군 | 주요 속성 |
| :--- | :--- | :--- |
| `Lawyer` | 변호사 | 전문 분야, 소속, 위치 |
| `TaxAccountant` | 세무사 | 전문 분야, 소속, 위치 |
| `Accountant` | 공인회계사 | 전문 분야, 소속, 위치 |
| `LaborAttorney` | 노무사 | 전문 분야, 소속, 위치 |
| `PatentAttorney` | 변리사 | 전문 분야, 소속, 위치 |

지오코딩 API를 통해 위치 좌표 변환 후 지도에 표시
